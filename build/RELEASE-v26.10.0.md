# DevShell v26.10.0 · 构建 20261018118

Phoenix 分支（[yuhongwei380/DevShell](https://github.com/yuhongwei380/DevShell)）首个按新版本号规则发布的版本。

## 版本号规则

- 版本号 `vX.Y.Z`：X 为年份后两位，Y 为月份（不补零），Z 为当月第几个版本（从 0 起）。
- 内部构建号 `ApplicationBuild`：`YYYYMMDD` + 三位序号，每次发布递增，更新防回退依赖它。

## 本轮变化

- 内置更新检查与下载切换为 GitHub Releases；描述文件默认不带签名，保留 SHA-256、大小、版本与构建防回退校验。
- 界面字体为阿里巴巴普惠体 3.0 55 Regular（免费商用），替换 IBM Plex Sans SC；旧界面字体设置自动迁移。
- 移植上游构建 107–114：固定连接栏（书签按钮固定到顶部，左键快速连接或切换、右键取消固定、重启保留）；未连接时 `ping 主机` 直接输出到终端，`-t` 持续探测、Ctrl+C 结束；本机提示区跟随 Shell 字体与缩放；「跟随终端目录」复选框在右侧停靠时保持可见。
- 按上游构建 108–109 精简：移除 AI 助手、加密同步、FinalShell 导入与开启动画，启动直达主界面。
- 修复 Windows 启动附带控制台日志窗口：发行构建使用 GUI 子系统（`-H windowsgui`），日志仅写入 `data/logs`。
- 构建 20261018116：「断开连接」「重新连接」「清除终端」上移至会话顶部与保存连接、固定、SFTP 同排；修复「固定」按钮“界面偏好包含无效项目”报错与固定不持久的问题。
- 构建 20261018117：「当前连接」徽标从会话标签移到会话头部与连接状态合并显示；固定连接栏并入顶部会话栏、位于标签左侧；会话头部加高、按钮加大并加描边，与终端底色更易区分；系统信息新增独立显卡（NVIDIA / AMD）显存与占用率展示，多卡按 GPU0、GPU1… 区分，核显不展示；IPv4/IPv6 改为展示真实网卡地址（含内网），排除 Docker 等虚拟接口。
- Windows 发行全面更名为 **DevShell**：`DevShell-Setup-x64.exe`、`DevShell-windows-x64.zip`、`DevShell.exe`，开始菜单／桌面快捷方式与卸载入口同步更名；安装器自动沿用此前 DengShell 的安装目录与全部数据，并清理旧程序文件、旧快捷方式与旧卸载登记。
- 设置菜单新增「检查更新」（位于「关于本软件」之前）：手动触发全新检查，发现新版本弹出更新对话框，可下载并自动安装重启；已是最新或网络不可用时给出明确提示。
- 界面文案全面改用 DevShell 品牌：窗口标题、设置标题、退出 / 解锁对话框、更新对话框、帮助手册、托盘菜单与系统错误弹窗均显示 DevShell；内部数据目录、配置加密标识、终端集成协议与更新缓存标识不变，历史配置与凭据无需迁移。
- 构建 20261018118：会话 `exit` / `logout` 后标签落回**本机提示符**（参考 Xshell）——标签与终端内容保留，命令框可直接输入 `ssh 用户@主机`（当前标签内连新地址）、`reconnect`（原地址重连）、`ping 主机 [-t]`（本机探测）、`exit`（关闭标签）、`help`（命令列表），无需关闭标签再去首页重输。同时修复正常退出被误报为异常断开：远端 Shell 自行结束记 DS-100 用户主动断开（ℹ️），不再显示 ⚠️ DS-210；仅通道 / 传输异常仍记 DS-210。
- 界面展示版本为 `ver.Phoenix · v26.10.0`。

## 升级说明

- 本轮提供 Windows 安装版、绿色 ZIP，Linux DEB、RPM、pacman 与通用安装包，以及源码。
- 页面中的 `up.exe` / `up.exe.json` 等 `up.*` 文件是**内置自动更新的载荷**（改名后的新版程序 + 校验描述），由已安装客户端启动检查后自动下载替换，无需手动下载运行；首次安装请选 `DevShell-Setup-x64.exe` 或对应平台的安装包。
- **更名提示**：更新描述文件的产品标识已改为 `DevShell`，此前 DengShell 版（构建 ≤20261018116）的内置自动更新不会识别本次更新，请手动下载安装一次 `DevShell-Setup-x64.exe`；安装器会自动沿用旧安装目录与连接、密钥等全部数据，之后内置更新继续正常工作。
- 由本分支此前发行包安装的 Windows、DEB、pacman 客户端可通过内置更新获取后续版本；上游旧客户端仍检查原官网，不会收到本分支更新，需手动安装一次本分支发行包。
- 连接、密钥、字体及背景沿用原配置目录。
