# 界面字体

当前仅内置阿里巴巴普惠体 3.0 55 Regular（Alibaba PuHuiTi 3.0）TTF 正文字重，经本分支 GitHub Release 分发。来源版本与 SHA-256 见 `web/assets/ui-fonts/catalog.json`；许可说明随文件保留，完整官方许可证以 https://fonts.alibabagroup.com/ 为准。

其余界面字体移至官网在线库，来源详见 `library-sources.json`，构建方法见本目录 `README.md`。手动导入界面字体保持重启生效；在线库下载经过固定目录和文件校验后可直接启用。用户原有自定义字体不删除。
