# DevShell v26.10.0 · 构建 20261022139

Phoenix 分支（[yuhongwei380/DevShell](https://github.com/yuhongwei380/DevShell)）；版本号 `vX.Y.Z`，内部构建号 `YYYYMMDD` + 三位序号递增防回退。

## 本次变化

- 修复：连接 OpenWrt／路由器一类 SSH 服务器稳定报「无法创建或启动远端终端」，终端还没打开就断开
  - 原因是终端启动脚本作为一条请求发送时约 26 KB，dropbear 嫌长直接拒绝并顺手结束连接（路由器日志 `String too long`）
- 调整：启动脚本改为压缩下发（gzip + base64），约 7 KB，嵌入式设备和普通 Linux 服务器都保留提示符着色、命令集成与当前目录跟随
- 新增：远端缺少 `base64` 或 `gzip` 时自动改用最普通的登录 shell，终端照常可用，不会卡住
- 新增：脚本仍超过长度上限时不再发送，直接用最普通的登录 shell 打开，并在终端里说明「已跳过提示符集成」
- 新增：断连诊断更具体——会记录究竟是哪一步请求失败（创建通道／申请伪终端／启动脚本／回退 shell），并单独记录启动脚本被跳过

## 升级说明

- Windows：内置自动更新即可；首次安装选 `DevShell-Setup-x64.exe`，`up.*` 文件是更新载荷，无需手动下载。
- OpenWrt／嵌入式设备：升级到本构建后可以直接连；如果仍连不上，诊断里会写明失败的是哪一步请求和错误类别，据此再收窄。
- 提示符集成依赖远端有 `base64` 与 `gzip`；缺任一个终端仍可用，只是不加载提示符集成。
