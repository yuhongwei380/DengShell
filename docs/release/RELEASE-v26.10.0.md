# DevShell v26.10.0 · 构建 20261018129

Phoenix 分支（[yuhongwei380/DevShell](https://github.com/yuhongwei380/DevShell)）；版本号 `vX.Y.Z`，内部构建号 `YYYYMMDD` + 三位序号递增防回退。

## 近期变化

- 构建 20261018129：修复桌面窗口打开后所有功能报「桌面接口尚未就绪」——上一构建的结构整理改变了前端桥接路径但未同步，桌面模式完全不可用；已更新到 20261018128 的用户请手动安装一次最新安装包。
- 构建 20261018128：仓库结构整理——前端、脚本、文档与 Go 源码分目录归位，程序行为不变。
- 构建 20261018127：仅发布 Windows 安装包与 macOS 通用包，停止 Windows 绿色版与 Linux 包；已装 Linux 版可继续使用，更新检查明确提示已停发。
- 构建 20261018126：链接栏取消固定仅通过 × 按钮并二次确认，不再支持右键取消固定。
- 构建 20261018125：新增「串口终端」连接类型（一键检测串口，波特率 / 校验 / 流控可配，与 SSH 一样保存、分组、固定）；服务器管理按钮移入标签行；命令输入框加高。
- 构建 20261018124：链接栏取消固定需二次确认；SFTP「跟随终端目录」默认开启。
- 构建 20261018123：启用全新「Dev❯_」logo；正常退出不再写入断开日志，仅异常断开记录；断开后隐藏闪烁光标。
- 构建 20261018122：链接栏标签常显，固定项最多 7 个、超出收入下拉。
- 构建 20261018121：修复「更新文件与本次检查结果不一致」，手动检查后可直接下载；链接栏上移顶部行。
- 构建 20261018120：头部布局重构——链接栏与标签行移入终端列，窗口按钮固定右上角，快速连接「+」左对齐。
- 构建 20261018119：修复「检查更新失败」（适配 GitHub 新资产下载域名）；固定栏改为独立高亮条带。
- 构建 20261018118：会话退出后落回本机提示符（`ssh` / `reconnect` / `ping` / `exit` / `help`）；正常退出不再误报异常断开。
- 构建 20261018117：「当前连接」徽标移入会话头部；系统信息新增独立显卡与真实网卡地址。

## 升级说明

- 首次安装选 `DevShell-Setup-x64.exe`；`up.*` 文件是内置自动更新载荷，无需手动下载。
- 构建 ≤20261018118 的旧版无法内置更新到新版，请手动安装一次最新 `DevShell-Setup-x64.exe`；连接、密钥等数据自动沿用。
- 构建 20261018128 的桌面窗口不可用（所有请求报「桌面接口尚未就绪」）且无法内置更新，请手动安装一次最新 `DevShell-Setup-x64.exe`；数据自动沿用。
