# DevShell v26.10.0 · 构建 2026102301

本发布把 v26.10.0 重新基线到新构建号规则 `YYYYMMDD` + 两位当日序号（`2026102301`，原构建 `20261023145`），软件内容与原构建一致。原 v26.10.0 下载页与标签已下架：曾安装 `20261023145` 等旧十一位构建的用户需**手动安装本构建一次**，之后可继续内置更新升级到 v26.10.1。

以下汇总该版本历次正式构建的变化；完整记录见 CHANGELOG.md 与历史发版说明。
