# DevShell v26.10.0 · 构建 20261021138

Phoenix 分支（[yuhongwei380/DevShell](https://github.com/yuhongwei380/DevShell)）；版本号 `vX.Y.Z`，内部构建号 `YYYYMMDD` + 三位序号递增防回退。

## 本次变化

- 新增：连接时手动输入的密码／私钥口令，在连接成功后自动加密保存到该连接
  - 重启、双击服务器列表、点链接栏固定项都不再重复索要；临时快速连接、SSH Agent 与密钥库内私钥不参与保存
- 新增：已保存的密码失效时（服务器拒绝认证），本次验证通过的凭据自动替换旧值，不再每次启动先试一遍失效的旧密码
- 新增：编辑连接里取消勾选「在本机保存密码／口令」后，本次运行内不再自动写回，显式拒绝优先于自动保存
- 新增：远程桌面输入的密码同样在连接成功后保存
- 修复：固定到链接栏时若本窗口没有凭据可携带，此前静默保存成无密码连接；现在明确提示下次连接仍需输入
- 新增：快速连接保存对话框说明凭据是否会被保存（SSH Agent／无凭据／默认保存）
- 调整：macOS 支持范围收敛为最近的几个正式版（15、26、27），最低系统要求由 13 提高到 15；构建前校验所用 SDK 不低于该值，CI 构建机改用 macOS 15

## 升级说明

- Windows：内置自动更新即可；首次安装选 `DevShell-Setup-x64.exe`，`up.*` 文件是更新载荷，无需手动下载。
- macOS 13／14：本版本最低系统为 15.0，在更旧的系统上无法启动；请升级到 macOS 15 及以上，或继续使用旧版本。
- 之前固定到链接栏、每次都要重输密码的连接：升级后第一次输入密码并连接成功即自动保存，之后免输。
