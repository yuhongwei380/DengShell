# DevShell v26.10.1 · 构建 2026102401

本版把 v26.10.0 之后的全部改动（测试版与中间构建）统一为正式版一次性发布，并把构建号切换为 `YYYYMMDD` + 两位当日序号。新的十位构建号在数值上小于历史十一位构建号，内置更新器无法自动推送升级：此前安装的任意版本（含测试版）需**手动安装本构建一次**，之后继续内置更新。

## 本次变化

- 调整：v26.10.0 以来的全部改动统一发布为 v26.10.1 正式版，构建号切换为 `YYYYMMDD` + 两位当日序号。
- 调整：监控面板取消左右位置配置，固定在左侧；外观配置改为「监控面板 显示／隐藏」，隐藏时终端区占满全宽。
- 修复：窗口缩到最小宽度时，终端头部的断开／重连／清屏与文件面板按钮被均匀散开，现紧凑成组靠右排列。

## 过往功能说明

连接与会话：

- 新增 **新选项卡** 独立初始页；会话标签单行横向滚动，右侧提供左右导航与全部标签汇总列表。
- 新增 连接卡片右键 **移动到…** 分组；顶层及子分组支持同级拖拽排序与 `Alt + ↑ / ↓`，顺序保存后重启保留。
- 新增 链接栏置顶连接，支持拖拽排序与跨列表移动，溢出项折叠到 **︙** 列表，按窗口宽度自动重排。

终端与文件：

- 新增 终端内 `rz` / `sz` 桥接 SFTP 上传／下载，跟随终端当前目录。
- 新增 未连接时命令条 ↑ / ↓ 调出本机最近 50 条输入，跨重启保留。
- 新增 SFTP 面板首次启动默认收起；文件命令收进右键菜单，单文件原样下载、目录打包后下载，传输进度以圆环常显百分比。
- 修复 Windows 原生选择框导致鼠标指针消失、下载保存框误报无权限。

监控与诊断：

- 调整 磁盘监控只显示总容量大于 10 GB 的挂载点，悬停查看完整路径与可用空间；左侧监控栏固定 304 px，右侧 SFTP 面板固定 420 px（小窗口相应收窄）。

外观与安装：

- 新增 设置中的 **外观配置** 入口，集中管理界面／Shell 字体与颜色、提示符颜色、背景管理器与恢复默认布局。
- 调整 Windows 安装向导检测并协调关闭运行实例，文件替换失败自动回滚，统一品牌文字与中文字体。

更新：

- 新增 内置更新（Windows / macOS），更新提示与离线更新日志按 **新增／修复／调整** 显示绿／橙／蓝分类标签。
